📖 Guia do Back-End & APIs

1. O que é o Back-End?

É o "cérebro" nos bastidores da aplicação. Enquanto o Front-End é a tela do cinema que você vê, o Back-End gerencia o estoque de bilhetes, valida pagamentos, grava compras no banco de dados e coordena as regras de negócio.

2. O que é uma API e Requisições HTTP?

API (Application Programming Interface) é o balcão de atendimento do cinema. As aplicações do cliente (site/mobile) enviam requisições HTTP com pedidos específicos:

  • GET: Busca dados sem alterar nada (ex: consultar cartaz de filmes ou preço de pipoca).
  • POST: Envia dados para criar/processar algo novo (ex: registrar a compra de um ingresso).

3. O que é o Event Loop no Node.js?

No Node.js, existe apenas uma thread principal que processa as requisições em uma fila chamada Event Loop. Ele pega as requisições que vão chegando e as executa uma a uma sem travar a aplicação. No jogo, você faz o papel do Event Loop!

4. O que é Timeout & Status HTTP?

Se o servidor demorar muito para dar um res.send(), o cliente desiste e gera um Timeout (Erro 500/503). Quando você responde com a rota certa a tempo, o servidor retorna status 200 OK!
